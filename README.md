# football-book

A real-money Premier League betting research pipeline: three parallel books
(Claude alone, Codex alone, debated conclusion) tested against identical
singles at identical prices, judged primarily on closing line value rather
than profit and loss at this sample size. Sequel to `earnings-lab`.

Start with `CLAUDE.md`, then `spec/methodology.md` — the frozen rule set. Two
sections of the methodology are still open and must be set before the first
bet: the real-money scope of the three books (section 4), and the minimum
edge threshold (section 7).

See `NOTICE.md` before reading anything else in this repository as advice —
it isn't. See `reference/earnings-desk-handoff.md` for the full reasoning
behind every rule here.
