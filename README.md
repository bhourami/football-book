# football-book

A real-money Premier League betting research pipeline: three parallel books
(Claude alone, Codex alone, debated conclusion), each with its own real £200
bank, tested against identical singles at identical prices, judged primarily
on closing line value rather than profit and loss at this sample size.
Sequel to `earnings-lab`.

Start with `CLAUDE.md`, then `spec/methodology.md` — the frozen rule set.
All methodology sections are now decided (last: the 3-point minimum edge
threshold, set 13 September 2026); bet one can proceed under it as written.

See `NOTICE.md` before reading anything else in this repository as advice —
it isn't. See `reference/earnings-desk-handoff.md` for the full reasoning
behind every rule here.

Published, plain-language standings live at
[football-book-reports](https://github.com/bhourami/football-book-reports).
